# 🎓 Prachi AI – Multilingual AI Study Assistant

An AI-powered study assistant that answers student doubts in **Hindi, Marathi and English**.

## 🔗 Live Demo
👉 https://prachi-ai.streamlit.app

## ✨ Features
- Ask study questions in Hindi, Marathi or English
- Simple, easy-to-understand explanations
- Clean chat interface
- Daily usage limit to keep the app free
- Installable on phone like an app

## 🛠️ Built With
- Python
- Streamlit
- Google Gemini API
- Streamlit Community Cloud

## ▶️ Run Locally
```
pip install streamlit google-genai
```
Create `.streamlit/secrets.toml`:
```
GEMINI_API_KEY = "your-key-here"
```
Run:
```
streamlit run app.py
```
